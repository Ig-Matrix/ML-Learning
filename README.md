# ML Learning

My machine learning practice repo. Each project lives in its own folder with its own notebooks, data, README and requirements file, the same way the Dataquest project walkthroughs repo is laid out.

I usually start from a guided walkthrough, type the code myself, then run my own experiments and write up what I found in my own words.

## Projects

| Folder | What it does | Main tools |
|---|---|---|
| [olympic_medal_prediction](olympic_medal_prediction) | Predicts how many medals a team will win at the Olympics with linear regression, then tests which features actually help | pandas, scikit-learn, seaborn |

More folders will be added as I work through new projects.

## Running a project

Every project has its own `requirements.txt` and setup steps in its own README. Open the project folder, create a virtual environment there and install from that file.
